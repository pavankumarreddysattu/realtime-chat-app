# Real-Time Chat App

MERN-stack chat application (work in progress).

## Tech stack
Node.js, Express, MongoDB (Mongoose), React (Vite), Socket.IO

## Status
- Done: user signup, login, logout with JWT and bcrypt
- In progress: real-time messaging with Socket.IO, chat UI

## Run locally
Backend:

    cd backend
    npm install
    cp .env.example .env   (then fill in your values)
    npm run dev

Frontend:

    cd frontend
    npm install
    npm run dev
